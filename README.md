# Tic-Tac-Toe Game

A simple browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features
- Play against another player
- Play against an unbeatable computer AI
- Track scores for O, X, and draws
- Customize player names and match length
- Keyboard-friendly controls

## How to Run
1. Open the project folder in your browser.
2. Open the file `index.html` directly, or serve the folder with a local server.
3. Start playing the game.

## Project Files
- `index.html` - Main game layout
- `style.css` - Styling for the game
- `first.js` - Game logic and AI
